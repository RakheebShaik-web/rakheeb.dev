# Rakheeb Shaik — Quant Portfolio

A personal portfolio for Rakheeb Shaik, an algorithmic trader and quant developer building systematic trading tools across U.S. equities and Indian options.

**Live site:** [rakheeb.vercel.app](https://rakheeb.vercel.app/)

## Overview

The site presents selected trading systems, technical infrastructure, and the research-to-execution process behind the work. Its visual direction combines editorial typography, terminal-inspired details, a structured grid, and probability-path artwork with a restrained black, cream, and orange palette.

### Featured systems

- Automated U.S. stock trading bot
- NSE options selling system
- Quant screener for investment and trading opportunities

### Interface details

- Responsive desktop and mobile layouts
- Dark and light themes
- Animated navigation menu
- Sticky section progress indicator
- Touch-aware tool grid
- Integrated probability-path hero artwork
- Direct email, LinkedIn, and GitHub links

## Tech stack

- React
- Vite
- CSS
- Vercel

## Run locally

Requirements: Node.js and pnpm.

```bash
git clone https://github.com/RakheebShaik-web/rakheeb.dev.git
cd rakheeb.dev
pnpm install
pnpm dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Production build

```bash
pnpm build
pnpm preview
```

The optimized production output is generated in `dist/`.
